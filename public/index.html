    How it works — notes for judges

    1. Pick an amount ($1 / $5 / $10 / $25 or custom). Amounts are validated (zero, negative and non-numeric values are rejected) before any payment starts.
    2. Compose with AI. The “AI Tip Message Composer” drafts a personal message from a tone + your name + a detail about the creator. It is a client-side smart composer (template + variation engine, 500 message combinations per tone, no repeats) so the demo needs zero API keys. A real LLM can be dropped into the single function aiGenerateMessage() in public/app.js without touching anything else.
    3. Pay with PayPal. Checkout uses the official PayPal JavaScript SDK and the standard Orders flow: createOrder with the tip amount (the message rides along in custom_id) and capture inside onApprove. PayPal is the payment rail end-to-end — no cards or balances are handled by this app.
    4. Dual path, honestly labelled. With a sandbox client-id in public/config.js you get the real PayPal Checkout (sandbox). Without one, the app runs a Demo Mode that simulates the same created → approved → captured states with demo order IDs, so the full journey is testable with no credentials at all.
    5. Close the loop. After capture, the success screen shows the order ID and the delivered message, and the creator gets an “AI Thank-You Reply” draft — because a tip that gets acknowledged publicly brings the next tip.

    Run it: npm start, then open http://localhost:4174. Run the automated checks: npm run verify.
